# PixLens · 图片文字提取工具

一款完全免费、**本地离线**的图片文字提取（OCR）软件。
无需联网、无需注册、不上传图片，识别结果只保存在你自己的电脑上。

## ⬇️ 下载使用

无需安装 Python，下载解压即可使用：

**[👉 前往下载 v1.2.0（Windows）](https://github.com/G95467/PixLens/releases/tag/v1.2.0)**

> 在 Release 页面底部的「资产 / Assets」中，下载 `PixLens-v1.2.0.zip`，解压后双击 `图片文字提取工具.exe` 即可。

## 快速使用

解压后双击运行 `图片文字提取工具.exe`，然后：

1. 点击「选择图片」，从电脑中选择一张 **JPG / PNG** 图片（也支持 BMP / WEBP）；
2. 点击「开始识别」，稍候片刻；
3. 识别出的文字显示在右侧，点击「复制文字」即可粘贴到任何地方。

### 表格提取

如果图片中包含表格：

1. 选择包含表格的图片；
2. 点击「表格提取」按钮；
3. 程序自动识别表格结构，并在**桌面**生成一个 Excel 文件（`.xlsx`），文件名带时间戳；
4. 同时在右侧结果区显示表格预览（制表符分隔），可直接复制。

### 主题切换

顶栏右上角有「深色模式」开关，点击可在**深色 / 浅色**两种主题间切换，界面布局不变。

## 功能特点

| 特性 | 说明 |
| --- | --- |
| 完全免费 | 基于开源 RapidOCR 引擎，无任何收费、广告或次数限制 |
| 本地离线 | 识别在电脑本地完成，图片不会上传，断网也能用 |

| 表格提取 | 自动识别图片中的表格结构，导出为桌面 Excel 文件 |
| 深色/浅色主题 | 顶栏开关一键切换，界面布局保持不变 |
| 启动快速 | 采用目录模式打包，无需解压，低配电脑也能秒开 |
| 界面流畅 | 识别在后台线程进行，界面不卡顿，支持窗口缩放 |

## 文件说明

```
图片文字提取工具/
├── 图片文字提取工具.exe   ← 主程序（仅 6MB，双击即运行，启动飞快）
├── _internal/            ← 运行库（DLL、模型等，勿删）
├── main.py               ← 源代码（程序主体）
├── app_icon.ico          ← 程序图标
├── requirements.txt      ← Python 依赖清单
└── build.bat             ← 一键重新打包脚本
```

> **v1.2 轻量化说明**：采用目录模式（onedir）打包，启动时无需解压，低配电脑也不会卡顿。exe 仅 6MB，配合 `_internal` 运行库使用，请勿删除或移动 `_internal` 文件夹。

## 重新打包（可选）

如果你修改了源代码，想重新生成 exe，只需：

1. 电脑上安装 Python 3.9+（安装时勾选 “Add Python to PATH”）；
2. 双击运行 `build.bat`，等待打包完成；
3. 新的 exe 会生成在 `dist` 文件夹中。

## 命令行自检（开发者用）

打包后的 exe 支持隐藏自检模式，用于验证识别功能是否正常：

```
图片文字提取工具.exe --selftest <图片路径> <输出文本文件>
```

## 常见问题

- **首次识别稍慢**：首次使用时 OCR 模型需要加载到内存，稍等几秒即可，之后识别会很快；
- **杀毒软件提示**：个别杀软会对未签名的程序误报，添加信任即可；本项目完全开源，可自行查看源码；
- **识别不准确**：图片越清晰、文字越正，识别率越高；可尝试放大或裁切后重试。
